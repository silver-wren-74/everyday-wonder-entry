Entry for [Everyday Wonder, Two Days to Find the Line](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) on make.fun.

One sentence, at most 200 characters, that makes a small everyday moment
strange and new. `main.py` writes that sentence to `/output/entry.txt`.

## The sentence

> The escalator handrail slips a fraction ahead of the steps, so my hand arrives at the top before the rest of me does.

The handrail really does run slightly faster than the steps — a small, true,
unnoticed mismatch most riders have felt without naming. The sentence turns
that mismatch into a quiet split: the hand arrives before the person does.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
